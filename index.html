Getting started

  1. Add a box and use its suggested number.
  2. Write that number on the cardboard box.
  3. Record its contents, quantities, room and optional photo.
  4. Find it later using the box number or item search.
  5. Mark it Loaded, Delivered or Unpacked as you move.
  6. Export a JSON backup regularly, especially before updating the app.

How to use V4

  1. Add a box and assign its room.
  2. List contents, one item per line, and optionally record exact quantities below.
  3. Write the box number clearly on the cardboard box using a marker pen. No printing required.
  4. Use Find items to locate belongings, or Find box number to open a numbered box.
  5. Optionally add a photo, mark heavy boxes and use the Moving checklist.
  6. Update each box as it moves from Packed to Loaded, Delivered and Unpacked.

Each device stores its own inventory. Use Export and Restore to transfer your records to another device.
